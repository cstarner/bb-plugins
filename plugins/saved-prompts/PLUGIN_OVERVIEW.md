Send your agent a prompt you type all the time — "pull in the latest from
main and fix any merge conflicts" — with one click from the top of a thread.

## What you get

- A **Send button in the thread header** with a dropdown of the prompts saved
  for that thread's project. Pick one and it is sent to that thread's agent,
  exactly as if you had typed it.
- An **editor for the list**, from "Edit prompts…" in the dropdown or on this
  plugin's page in Settings. A prompt is a short name and the text to send.

## How it works

Each project has its own list of prompts, kept in the plugin's own storage
rather than in the repository, so they are yours and not your team's. Picking
one sends it straight away: an idle agent starts on it, and a busy one gets it
when it is free.

## Requirements

Nothing to install.
